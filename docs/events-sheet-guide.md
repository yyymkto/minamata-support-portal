# イベント登録用スプレッドシートの準備と使い方

「イベント」タブに、Instagramなどで見つけたイベントを手で追加するためのGoogleスプレッドシートの準備手順です。
最初の準備は15分ほどで終わります。準備が済んだら、あとは行を書き足すだけです。

設計の詳細は `docs/agent-notes/design-specs/2026-09-21_events-tab.md` を参照してください。

主催者からの掲載申し込み（Googleフォーム）の準備と使い方は、後半の「[フォームからの掲載申し込み](#フォームからの掲載申し込み)」にあります。

---

## 最初の準備（1回だけ）

### 1. スプレッドシートを作る

1. Googleスプレッドシートで新しいシートを作ります。名前は自由です（例：「くらしナビ イベント登録」）。
2. 1行目のA1セルをクリックし、下の1行をまるごとコピーして貼り付けます。A〜Jの10列に、見出しが自動で分かれて入ります。

   ```
   非表示	イベント名	開始日	終了日	時間	場所	概要	主催	リンク	情報元
   ```

   列の名前で読み込んでいるので、**見出しの文字は変えないでください**（列の順番を入れ替えるのは大丈夫です）。

> 💡 手順1・2は、Googleスプレッドシートの Gemini に頼んで作ってもらうこともできます。
> そのときの指示文は、この手順書の最後の「付録：Geminiへの指示文」にあります。
> 作ってもらったあと、見出しの文字が1文字も違わないことだけは必ず確認してください。

### 2. 日付の列に入力規則を付ける（書き間違い防止）

1. C列とD列（開始日・終了日）の列見出しをクリックして、2列を選択します。
2. メニューの「データ」→「データの入力規則」→「ルールを追加」を開きます。
3. 条件を「有効な日付」にし、「詳細オプション」で「入力を拒否」を選んで「完了」を押します。

これで、「来週」のような日付でない文字は入力できなくなります。

### 3. ウェブに公開する

1. メニューの「ファイル」→「共有」→「ウェブに公開」を開きます。
2. 「リンク」タブで、左側を「ドキュメント全体」から **登録用のシート名（例：シート1）** に変え、
   右側を **「カンマ区切り形式（.csv）」** にします。
3. 下の「公開するコンテンツと設定」を開き、**「変更されたときに自動的に再公開」にチェックが入っている**ことを確認します。
4. 「公開」を押し、表示されたURL（`https://docs.google.com/spreadsheets/d/e/…/pub?…output=csv` のような形）をコピーします。

> ⚠ 公開したシートは、URLを知っていれば誰でも見られます。サイトに載せてよい情報だけを書いてください。
> 編集できるのは今までどおり吉野さんだけです。

### 4. GitHubにURLを登録する

1. GitHubでこのリポジトリを開き、上のメニューの「Settings」を開きます。
2. 左側の「Secrets and variables」→「Actions」を開きます。
3. **「Variables」タブ**（「Secrets」ではありません）を選び、「New repository variable」を押します。
4. Name に `EVENTS_SHEET_CSV_URL`、Value に手順3でコピーしたURLを貼り付けて「Add variable」を押します。

登録できたらClaude Codeに伝えてください。試しに1行入れて、サイトに反映されるかを一緒に確認します。

## ふだんの使い方

入力した内容は、**翌朝7時の自動更新**でサイトに反映されます。
すぐに反映したいときは、GitHubの「Actions」→「水俣市くらしナビ 自動更新・デプロイ」→「Run workflow」で手動実行できます
（反映まで15分ほどかかります）。

### イベントを追加する

1行に1イベントを書きます。

| 列 | 書くこと | 例 |
|---|---|---|
| 非表示 | 空欄のまま | |
| イベント名 | 必須 | 秋の手づくり市 |
| 開始日 | 必須 | 2026/10/25 |
| 終了日 | 複数日のときだけ | 2026/10/26 |
| 時間 | 分かれば | 10:00〜15:00 |
| 場所 | 分かれば | 道の駅みなまた |
| 概要 | 1〜2文、120字くらいまで | 手づくりの雑貨や焼き菓子が並びます |
| 主催 | 分かれば | 手づくり市実行委員会 |
| リンク | できるだけ入れる | Instagram投稿のURL |
| 情報元 | 空欄でOK | 空欄なら、リンクがInstagramのときは「Instagram」と表示されます |

- 終わったイベントは、サイトから自動で消えます。スプレッドシートの行は消さなくても大丈夫です。
- 追加する前にサイトのイベントタブを見て、**すでに載っていないか**確認してください。
  市や観光物産協会のサイトに出ているイベントは自動で載るので、二重になってしまいます。

### 自動で載ったイベントの日付・場所がおかしいとき（上書き）

1. サイトのイベントタブで、そのイベントの「詳細」ボタンのリンク（元記事のURL）をコピーします。
2. スプレッドシートに1行足し、「リンク」にそのURLを貼り、正しいイベント名・日付・場所などを書きます。

次の更新で、自動で読み取った内容がスプレッドシートの内容に置き換わります。

### 自動で載ったものを消したいとき（非表示）

1. 上と同じく、元記事のURLをコピーします。
2. スプレッドシートに1行足し、「非表示」に `x` など何か1文字、「リンク」にそのURLを書きます（他の列は空欄でOK）。

自分で追加したイベントを取り下げたいときは、その行の「非表示」に `x` を入れるか、行を削除してください。

### うまく載らないとき

- イベント名か開始日が空の行、開始日が日付として読めない行は、載りません。
- シートの公開をやめたり、見出しの文字を変えたりすると、サイトは**最後に読み込めた内容のまま**になります
  （イベントが消えてしまうことはありません）。
- 原因が分からないときはClaude Codeに聞いてください。読み込めなかった行は `public/data/_events_manual.json` の
  `warnings` に記録されています。

## フォームからの掲載申し込み

水俣市でイベントを企画している人が、Googleフォームから掲載を申し込めるようにする仕組みです。
申し込みは、吉野さんが中身を見て「承認」したものだけがサイトに載ります。
設計の詳細は `docs/agent-notes/design-specs/2026-09-28_event-submission-form.md` を参照してください。

```
企画者 ──フォーム──▶「フォームの回答 1」タブ（公開しない・連絡先を含む）
                          │ 吉野さんが「承認」列に x を書く
                          ▼
                     「掲載用」タブ（数式で自動。承認した行の、載せる項目だけ）
                          │ このタブだけをウェブに公開
                          ▼
                     翌朝7時の自動更新でサイトに反映
```

> ⚠ **いちばん大事なこと**：「フォームの回答 1」タブには申込者の連絡先が入ります。
> **このタブは絶対に「ウェブに公開」の対象にしないでください。** 公開するのは「シート1」と「掲載用」タブだけです。

### 準備の流れ

| 順番 | やること | 担当 |
|---|---|---|
| A | フォームを作る（下の「A. フォームを作る」） | 吉野さん（30分ほど） |
| B | 承認列と掲載用タブを作り、公開する（下の「B. 承認列と掲載用タブ」） | 吉野さん、数式の確認はClaude Codeと一緒に |
| C | 読み込むプログラムを直す | Claude Code |
| D | 回答タブが外から見えないことを確かめる | Claude Code |
| E | サイトに「掲載を申し込む」リンクを出して、受付を始める | Antigravity → 吉野さん |

**E が終わるまでは、フォームのURLを人に教えないでください**（テスト投稿は吉野さんだけで行います）。

---

### A. フォームを作る

#### A-1. スプレッドシートからフォームを作る

1. いつもの「くらしナビ イベント登録」スプレッドシートを開きます。
2. メニューの「ツール」→「新しいフォームを作成」を押します。
   フォームの編集画面が開き、スプレッドシートには「フォームの回答 1」というタブが自動で増えます。
   （この方法で作ると、回答が自動でこのスプレッドシートに入ります）

   > 💡 Googleフォームの画面から直接フォームを作ってしまった場合は、あとからつなげられます。
   > フォームの「回答」タブ →「スプレッドシートにリンク」→ **「既存のスプレッドシートを選択」** で、このスプレッドシートを選んでください
   > （「新しいスプレッドシートを作成」は選ばないでください）。それまでに送信した回答も「フォームの回答 1」タブに入ります。
3. フォームの一番上のタイトルを「**みなまた くらしナビ イベント掲載の申し込み**」にします。
4. タイトルの下の説明欄に、次の文をそのまま貼り付けます（直したいところがあれば直してかまいません）。

```
「みなまた くらしナビ」のイベント一覧への掲載を申し込むフォームです。

・このサイトは個人が運営する非公式サイトで、水俣市とは関係ありません。
・掲載するかどうかは、運営者が内容を確認して決めます。掲載できない場合もあり、その理由はお答えできないことがあります。
・掲載までに数日かかることがあります。掲載のご連絡はしませんので、サイトのイベントタブでご確認ください。
・入力いただいたイベントの情報（連絡先を除く）は、サイトで公開されます。
・連絡先は、内容の確認のためだけに使い、公開しません。イベント終了後、一定期間がたったら削除します。
・日時の変更や中止は、このフォームの「掲載内容の変更」「中止・掲載取り下げ」からお知らせください。

【掲載するもの】
水俣市内（または近隣）で開かれ、一般の方が参加・来場できる催し（祭り、マルシェ、スポーツ、講座、体験会、展示など）

【掲載しないもの】
・選挙・政治活動、宗教の勧誘、ネットワークビジネス等の勧誘を目的とするもの
・会員限定など、一般の方が参加できないもの
・お店の通常の営業・セールの宣伝
・日時・場所がはっきりしないもの
・法令や公序良俗に反するもの
```

#### A-2. 質問を作る

フォームは4つのセクション（ページ）に分けます。
右側の縦のメニューの「＋」で質問を、「＝」のようなアイコン（セクションを追加）でセクションを増やします。

> ⚠ **質問のタイトルは、下の表の「タイトル」の文字どおりにしてください。**
> 掲載用タブの数式が、タイトルの文字で列を探します。1文字でも違うと読み込めません。
> 補足したいことは、タイトルではなく「説明」に書きます（質問の右下の「⋮」→「説明」で説明欄が出ます）。

**セクション1（最初からあるセクション）**

| タイトル | 形式 | 必須 | 設定・説明 |
|---|---|---|---|
| 種別 | ラジオボタン | オン | 選択肢を3つ：`新規の掲載` / `掲載内容の変更` / `中止・掲載取り下げ`（この文字どおりに） |
| 同意 | チェックボックス | オン | 選択肢を1つ：`掲載基準と注意事項を確認しました` |

**セクション2**（セクションのタイトル：「イベントの内容」）

| タイトル | 形式 | 必須 | 設定・説明 |
|---|---|---|---|
| 変更するイベント | 記述式 | オフ | 説明：「『掲載内容の変更』のときだけ、今載っているイベント名と開催日を書いてください」 |
| イベント名 | 記述式 | オン | 回答の検証：「長さ」「最大文字数」40 |
| 開始日 | 日付 | オン | 「⋮」で「年を含める」にチェックが入っていることを確認 |
| 終了日 | 日付 | オフ | 説明：「複数日のときだけ」。「年を含める」を確認 |
| 時間 | 記述式 | オフ | 説明：「例：10時〜15時」 |
| 場所 | 記述式 | オン | 説明：「例：道の駅みなまた」 |
| 概要 | 段落 | オン | 説明：「どんな催しか、1〜2文で」。回答の検証：「長さ」「最大文字数」120 |
| 主催 | 記述式 | オン | 説明：「サイトに表示されます。団体名か、個人の場合は表示してよいお名前を書いてください」 |
| リンク | 記述式 | オフ | 説明：「詳しい情報が載っているページ（Instagramの投稿など）があれば」。回答の検証：「テキスト」「URL」 |

**セクション3**（セクションのタイトル：「中止・取り下げ」）

| タイトル | 形式 | 必須 | 設定・説明 |
|---|---|---|---|
| 中止するイベント | 段落 | オン | 説明：「イベント名と開催日、中止か掲載の取り下げかを書いてください」 |

**セクション4**（セクションのタイトル：「連絡先」）

| タイトル | 形式 | 必須 | 設定・説明 |
|---|---|---|---|
| 連絡先メールアドレス | 記述式 | オン | 説明：「内容の確認のためだけに使い、公開しません」。回答の検証：「テキスト」「メールアドレス」 |

> 💡 「回答の検証」は、質問の右下の「⋮」→「回答の検証」で出てきます。

#### A-3. 答えによって進むページを変える

「中止」を選んだ人に、イベントの内容を入力させないための設定です。

1. セクション1の「種別」の質問の右下「⋮」→「回答に応じてセクションに移動」を押します。
2. 各選択肢の右に行き先が出るので、次のようにします。
   - 新規の掲載 → セクション2
   - 掲載内容の変更 → セクション2
   - 中止・掲載取り下げ → セクション3
3. セクション2の一番下にある「セクション2以降」の行き先を「**セクション4に移動**」にします。
   （こうしないと、セクション2のあとに中止のページが出てしまいます）
4. セクション3の一番下は「次のセクションに進む」のままで大丈夫です。

#### A-4. フォームの設定

画面上の「設定」タブで、次のようにします。

- 「回答」を開く
  - 「メールアドレスを収集する」：**収集しない**（連絡先は質問で聞いています。「確認済み」にするとGoogleログインが必須になります）
  - 「回答を1回に制限する」：**オフ**（オンにするとGoogleログインが必須になります）
  - 「回答の編集を許可する」：**オフ**（変更は「掲載内容の変更」で出し直してもらいます）
- 「プレゼンテーション」を開く
  - 「確認メッセージ」に次の文を入れる：
    `お申し込みありがとうございました。内容を確認し、掲載する場合は数日以内にサイトのイベントタブに載ります。`

#### A-5. 新しい申し込みをメールで知らせてもらう

1. 画面上の「回答」タブを開きます。
2. 右の「⋮」→「新しい回答についてのメール通知を受け取る」を押します。

#### A-6. テスト投稿

作ったばかりのフォームは「下書き」の状態で、プレビューでは送信できません。先に公開します。

1. 画面右上の「**公開**」ボタンを押します。回答者の範囲を聞かれたら「リンクを知っている全員」のままにして公開します。
   （公開しても、URLを知らない人は開けません。受付を始めるまでURLは誰にも教えないでください）
2. 右上の「🔗」（回答者用のリンクをコピー）でURLをコピーし、ブラウザで開いて、次の2件を送信します。
   - 「新規の掲載」：イベント名「テスト申し込み」、開始日は来月のどこか、時間「10:00〜15:00」、場所・概要・主催は適当に、連絡先は吉野さんのメール
   - 「中止・掲載取り下げ」：中止するイベント「テスト申し込み」
3. 通知メールが届くこと、スプレッドシートの「フォームの回答 1」タブに2行入ることを確認します。

ここまでできたら、Claude Codeに「フォームを作った」と伝えてください（フォームのURLはまだ誰にも教えないでください）。

### B. 承認列と掲載用タブ

#### B-1. 「フォームの回答 1」タブに列を足す

1. 「フォームの回答 1」タブを開きます。
2. 1行目の、いちばん右の質問（連絡先メールアドレス）のさらに右の空いている列に、見出しを2つ書きます。
   - `承認`
   - `メモ`
3. タブの名前は「フォームの回答 1」のまま変えないでください。

#### B-2. 「掲載用」タブを作る

1. 画面左下の「＋」で新しいタブを作り、名前を `掲載用` にします。
2. A1セルをクリックし、次の1行をコピーして貼り付けます。A〜Hの8列に見出しが入ります。

   ```
   イベント名	開始日	終了日	時間	場所	概要	主催	リンク
   ```

3. A2セルをクリックし、次の数式をまるごとコピーして貼り付けます（2行目以降はこの数式が自動で埋めます。**A2より下には何も書かないでください**）。

   ```
   =ARRAYFORMULA(LET(
     h, 'フォームの回答 1'!A1:Z1,
     d, 'フォームの回答 1'!A2:Z,
     c, LAMBDA(n, CHOOSECOLS(d, XMATCH(n, h))),
     ok, (c("承認")<>"") * (c("種別")<>"中止・掲載取り下げ") * (c("イベント名")<>""),
     ymd, LAMBDA(v, IF(v="", "", TEXT(v, "yyyy/mm/dd"))),
     IF(SUM(ok)=0, "",
       FILTER(HSTACK(c("イベント名"), ymd(c("開始日")), ymd(c("終了日")), c("時間"), c("場所"), c("概要"), c("主催"), c("リンク")), ok))
   ))
   ```

   > 💡 貼り付けは、A2セルを1回クリックしてから、画面上の数式バー（`fx` の右の欄）に貼るのが確実です。
   > 数式を編集している途中でほかのセルをクリックすると、`D14` のようなセルの番地が数式に紛れ込み、エラーになります。
   >
   > この数式は、実際のシートで Claude Code がまだ動作を確認していません。
   > 赤い三角や `#N/A` などのエラーが出たら、そのまま Claude Code に伝えてください。

#### B-3. 承認を試す

1. 「フォームの回答 1」タブで、テストの「新規の掲載」の行の「承認」列に `x` を書きます。
2. 「掲載用」タブの2行目に「テスト申し込み」が出ることを確認します。
   - 開始日が `2026/10/25` のような形になっていること
   - 時間が `10:00〜15:00` のまま出ていること（数字や `10:00:00` に化けていないこと）
3. 「中止・掲載取り下げ」の行の「承認」にも `x` を書いてみて、**掲載用タブに増えない**ことを確認します。
4. 確認したら、2行とも「承認」の `x` を消します（掲載用タブが空になります）。

#### B-4. 「掲載用」タブをウェブに公開する

1. メニューの「ファイル」→「共有」→「ウェブに公開」を開きます。
2. 下の「公開するコンテンツと設定」を開き、公開する対象を確認します。
   - **「シート1」と「掲載用」だけ**にチェックが入っている状態にします。
   - **「ドキュメント全体」や「フォームの回答 1」は選ばないでください。**
   - 「変更されたときに自動的に再公開」にチェックが入っていることも確認します。
3. 上の「リンク」タブで、左側を **「掲載用」**、右側を **「カンマ区切り形式（.csv）」** にし、表示されたURLをコピーします。
   （シート1用のURLは、以前登録したものがそのまま使えます）
   - コピーしたURLの**末尾が `output=csv` になっていること**、`gid=` の数字が **`0` ではないこと**を確認します。
     `pubhtml` になっていたら右側が「ウェブページ」のまま、`gid=0` ならシート1を選んだままです。

#### B-5. GitHubにURLを登録する

以前の手順「4. GitHubにURLを登録する」と同じ画面で、もう1つ変数を追加します。

- Name：`EVENTS_FORM_CSV_URL`
- Value：B-4でコピーしたURL

登録できたら、Claude Codeに伝えてください。数式の結果と公開範囲を確認し、読み込むプログラムを直します（C・D）。

### ふだんの使い方（受付を始めてから）

#### 新しい申し込みが来たら

1. 通知メールが来たら、数日以内に「フォームの回答 1」タブを見ます。
2. 次を確認します。
   - 掲載基準（フォームの説明に書いたもの）に合っているか
   - サイトのイベントタブに、同じイベントがすでに載っていないか（市や観光物産協会のサイトから自動で載っていることがあります）
   - 分からないことがあれば、連絡先メールアドレスに問い合わせる
3. 載せるなら「承認」列に `x` を書きます。載せないなら空欄のままにし、「メモ」に理由を書いておくと後で迷いません。

翌朝7時の自動更新で載ります。急ぐときは、以前の手順と同じく Actions から手動実行します。

#### 「掲載内容の変更」が来たら

1. 新しい行（変更後の内容）の「承認」に `x` を書きます。
2. 「変更するイベント」に書かれた元の申し込みの行を探し、その「承認」の `x` を消します。
3. 変更の対象が、自動で載ったイベント（市や観光物産協会のサイトから）の場合は、元の行がありません。
   そのときは、シート1の「上書き」の手順（元記事のURLをリンクに入れて行を足す）で直します。

#### 「中止・掲載取り下げ」が来たら

1. 「中止するイベント」に書かれた元の申し込みの行を探し、その「承認」の `x` を消します。
2. 対象が自動で載ったイベントの場合は、シート1の「非表示」の手順で消します。

> 中止の申し込みそのものは、承認してもしなくてもサイトには出ません。なりすましの可能性があるので、心配なときは元の申込者の連絡先に確認してから消してください。

#### 載せたものをすぐ消したいとき

「承認」の `x` を消すのが基本です。うまく消えないときは、シート1に「非表示」の行（リンクにそのイベントのURL）を足すと、どこから載ったものでも消せます。

### 決めておくこと・定期的にやること

- **連絡先の削除**：イベント終了から3か月たった申し込みは、次の2か所から消します（年に数回まとめてで大丈夫です）。
  1. 「フォームの回答 1」タブの行（行を削除）
  2. フォームの「回答」タブ →「個別」表示で該当の回答を開き、ゴミ箱のアイコンで削除
     （スプレッドシートの行を消しても、フォーム側には回答が残っているためです）
- **共有範囲の見直し（年に1回）**：スプレッドシートの「共有」の相手と、「ウェブに公開」の対象が「シート1」「掲載用」だけになっているかを確認します。
- **承認する人を増やすとき**：スプレッドシートの「共有」で編集者に追加し、フォームも右上の「⋮」→「共同編集者を追加」で追加します。この手順書の「ふだんの使い方」を渡してください。
- **質問を変えたいとき**：**質問のタイトルは変えないでください。** 質問を変える・足すときは、先に Claude Code に相談してください（掲載用タブの数式とプログラムを合わせる必要があります）。
  選択肢の文字（特に `中止・掲載取り下げ`）も数式が使っているので、変えないでください。
- **迷惑な投稿が多くなったら**：フォームの「設定」→「回答」→「回答を1回に制限する」をオンにすると、Googleアカウントでのログインが必須になり、機械的な投稿が減ります（代わりに、Googleアカウントを持っていない人は申し込めなくなります）。

### うまく載らないとき・GitHubからIssueが来たとき

- 「イベントの投稿用シートを読み込めませんでした」というIssue（CのあとにClaude Codeが用意します）が来たら、次を確認します。
  - 「ウェブに公開」がやめになっていないか（B-4）
  - 「掲載用」タブの見出し（1行目）の文字が変わっていないか
  - 「掲載用」タブのA2セルにエラー（`#N/A` `#REF!` など）が出ていないか。出ていたら、フォームの質問のタイトルや、回答タブの「承認」の見出しが変わっていないかを見ます
  - 分からなければ、Issueの画面ごと Claude Code に見せてください
- 読み込めない間も、サイトは**最後に読み込めた内容のまま**表示されます（イベントが全部消えることはありません）。

## 付録：Geminiへの指示文

Googleスプレッドシートを新しく開き、右上のGeminiのボタンから、次の文をそのまま貼り付けて頼みます。

```
イベント情報を登録するための表を、このシートに作ってください。
このシートはCSVとしてウェブに公開し、プログラムが1行目の見出しの文字で列を見分けて読み込みます。
そのため、次の条件を必ず守ってください。

1. 1行目のA1〜J1に、次の10個の見出しをこの順番・この文字どおりに入れてください。
   前後に空白や記号、説明の文字を足さないでください。
   非表示 / イベント名 / 開始日 / 終了日 / 時間 / 場所 / 概要 / 主催 / リンク / 情報元

2. C列（開始日）とD列（終了日）の2行目以降に、データの入力規則を付けてください。
   条件は「有効な日付」、無効な値は「入力を拒否」にしてください。
   表示形式は「2026/10/25」のような 年/月/日 にしてください。

3. 1行目を固定し、太字にしてください。

4. 次のことはしないでください。
   ・見出しを2行にする、見出しの上にタイトル行や説明の行を入れる
   ・セルの結合
   ・「テーブルに変換」（表の機能）を使う
   ・サンプルのデータ行を入れる（2行目以降は空のままにしてください）

もし入力規則を付けられない場合は、付け方の手順を教えてください。
```

作ってもらったら、次の2つを目で確認してください。

- 1行目が「非表示 / イベント名 / 開始日 / 終了日 / 時間 / 場所 / 概要 / 主催 / リンク / 情報元」の10個だけになっていて、
  その上に行が無いこと
- C列に「来週」と入力してみて、はじかれること（確認したら消してください）

そのあと、「3. ウェブに公開する」から続けてください。
