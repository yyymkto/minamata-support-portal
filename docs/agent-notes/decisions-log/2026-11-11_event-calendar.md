# 2026-11-11 イベントのカレンダー連携は events.json から .ics を作る

## 決めたこと

- イベントの正本は今の `events.json`（4経路）のままにする。Googleカレンダーは正本にしない（吉野さんの判断）。
- 毎朝のGitHub Actionsで `events.json` から購読用の `data/events.ics` と1件ずつの `data/ics/<id>.ics` を作る。
- イベントタブに、購読ボタン（Google／iPhone・Mac）、カードごとの「カレンダーに追加」、カテゴリの絞り込みを足す。
- カテゴリは言葉の表で決める。タイトル先頭の `【…】` で手動指定もできる。

## 理由

- 66件のうち64件は自動抽出（広報45件・お知らせ19件）で、Googleカレンダーには入っていない。カレンダーを正本にすると手で入れ直すことになる。
- Googleの公開 .ics をブラウザで読むには中継サーバーが要り、Calendar API はページにAPIキーを書くことになる。自前の .ics ならどちらも要らない。

## 残るリスク

- Googleカレンダーの購読は、反映が1日ほど遅れることがある。Androidのアプリから購読できるかは実機で確かめる（設計書タスク7）。
- 終わったイベントは購読した人のカレンダーからも消える。
