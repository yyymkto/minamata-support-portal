# [2026-10-01] ホーム画面に追加できるようにする（ブックマークは手順の案内に留める）

**決めた人/エージェント**: 吉野さん（Claude Codeの設計案を了承）
**関係者**: 吉野さん、Claude Code

## 背景・課題

吉野さんから「このサイトをホーム画面に追加や、ブックマークに追加するようなボタンや機能を
作成したい」との依頼があった。Claude Codeが既存コードとブラウザ側の制約を調べたところ、
「押せば追加されるボタン」は一部の環境でしか作れないことが分かった
（iPhone・LINE等のアプリ内では不可、ブックマークはどのブラウザでも不可）。
また、サイトにはアイコンが1枚も無かった。

## 決定内容

設計書は `design-specs/2026-10-01_add-to-home-screen.md`。吉野さんが2026-10-01に次を了承した。

- **ボタンは常に押せる形にし、追加できる環境ではブラウザの追加確認を出し、
  それ以外では端末に合った手順を見せる。**
- **ブックマークはボタンにせず、手順の一文（Ctrl + D 等）で案内する。**
- **アイコン**は `bay`（`#1B4B5A`）の地に `paper`（`#F2F1EC`）の「み」1文字
  （Shippori Mincho Bold）。市章・市のロゴ・キャラクターは使わない。
- **ホーム画面の名前**は「くらしナビ」。正式名（追加の確認画面などに出る）は
  「みなまた くらしナビ（非公式）」のまま。
- **フィードタブに一行のお知らせ**（スマホのみ、一度消したら出さない）を出す。
- ホーム画面から開いたときはアプリのような画面（`display: standalone`）で開く。
  再読み込みの手段が無くなるため、画面に戻ったときに `last_updated` を確認し、
  変わっていれば読み込み直す。
- マニフェストとアイコンを `public/` に置き、`daily-update.yml` は `public/` 全体を
  `dist/` にコピーする形に変える。

## 却下した選択肢（あれば）

- **「ブックマークに追加」ボタン** → サイト側からブックマークを追加する方法が
  現在のブラウザに無い。押しても何も起きないボタンになる。
- **追加の合図（`beforeinstallprompt`）が届いたときだけボタンを出す** →
  iPhoneには合図が届かないため、iPhoneではボタンが一度も出ない。
- **Service Worker（オフライン用の仕組み）を入れる** → 現在は追加の確認を出すために
  必須ではない。毎朝データが変わるサイトで、キャッシュの扱いを誤ると古い情報を
  出し続ける危険がある。
- **`display: browser`（通常のブラウザで開く）** → Androidで追加の合図が出なくなる。
- **全画面の案内・繰り返し出る帯** → 2026-08-26の「誘導的な言い回しを避ける」方針に合わない。
- **OGP画像・プッシュ通知・LINEから直接ブラウザで開かせる仕組み** → 今回の範囲外。
