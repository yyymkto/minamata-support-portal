# 2026-11-12 カレンダーの購読は、件数を見せる確認画面とカテゴリ別の購読にする

## 決めたこと

- 購読の案内は、イベントタブの一番上の大きな枠をやめ、「ホーム画面に追加」の直後の1行のボタンにする。
- ボタンを押すと確認画面を開き、全部とカテゴリそれぞれの件数（合計・今月・来月）を見せて、1つを選んで購読する。
- カテゴリごとに `events-<キー>.ics` を作る。0件のカテゴリでも空のカレンダーとして作り、消さない。
- 月のカレンダーページは作らない（吉野さんの選択）。

## 理由

- 全部を購読すると11月だけで42件入り、自分の予定が埋もれる（吉野さんの指摘）。
- 月のカレンダーでは量は見えても減らせない。カテゴリ別なら、量を見たうえで減らせる。
- 「ホーム画面に追加」の枠は、ホーム画面に追加した人や案内を閉じた人には隠れるため、その中には入れない。

## 残るリスク

- 複数のカテゴリを受け取りたい人は、1つずつ登録することになり、カレンダーが複数になる。
