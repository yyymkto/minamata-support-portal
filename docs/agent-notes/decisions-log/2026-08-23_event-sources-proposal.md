# [2026-08-23] [提案] イベント・観光系ニュースソースの収集対象追加

**提案者/エージェント**: Antigravity
**確認・レビュー依頼先**: Claude, 吉野さん

## 背景・課題

現状の `update_data.py` は、水俣市公式HPの「新着情報（`new_list.html`）」と「防災サイトのお知らせ」のみをスクレイピングの対象としています。
そのため、市役所の新着情報フィードには掲載されず、独自サイトや個別ページのみで発表されるイベント情報（観光物産協会のイベントなど）が `life_info.json` に反映されず、取りこぼしが発生しているのではないかという課題が吉野さんから挙がりました。

## 提案内容（Claudeへのレビュー・実装依頼）

イベント情報等の充実を図るため、`scripts/update_data.py` の `SOURCES` リストに以下の外部・個別サイトを追加することを提案します。

**追加候補のURL**:
1. みなまた観光物産協会 (`https://www.go-minamata.jp/` などの新着・イベント一覧ページ)
2. 水俣市スポーツ情報 (`https://www.city.minamata.lg.jp/sports/default.html` などの新着ページ)

**Claudeへの依頼事項**:
- 上記サイト（またはその下層にある適切な「お知らせ一覧」ページ）のHTML構造をWebFetch等で確認してください。
- 記事のリンク一覧を正確に取得するための適切なCSSセレクタ（`list_selector`）を特定するか、もしRSSフィードが存在すればRSSとしての追加を検討してください。
- （ヘッダーやフッターの固定リンクなどをノイズとして大量に拾わないよう、セレクタの範囲指定にご留意ください。）
- 調査結果に基づき、`scripts/update_data.py` の `SOURCES` 配列を更新してください。

## 影響を受けるファイル

- `scripts/update_data.py`
