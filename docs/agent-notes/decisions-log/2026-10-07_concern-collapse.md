# [2026-10-07] 子育て支援制度タブを困りごとごとの折りたたみにする（2026-08-15の「常時展開」を一部変更）

**決めた人/エージェント**: 吉野さん
**関係者**: 吉野さん、Claude Code

## 背景・課題

週次監視のIssue #4で、水俣芦北圏域基幹相談支援センター「キャンバス」（2026-10-01開所）がストック候補として検知された。
追加すると子育て支援制度タブの制度が40件になり、改装の設計書（2026-09-16）で
「40件を超えたあたりで折りたたみか検索が必要」としていた目安に達する。
Claude Codeが「追加するなら、40件の目安をどうするかもあわせて決めたい」と相談した。

## 決定内容

- キャンバスを子育てタブ（「障がいのある子ども向けの支援を知りたい」）に追加する。
- **折りたたみを入れる。** 設計書は `design-specs/2026-10-07_concern-collapse.md`。
  - 困りごと（20個）ごとに閉じた状態で表示し、見出し・件数・中の制度名は閉じたままでも読めるようにする。
  - 2026-08-15の決定（`2026-08-15_stock-view-no-click.md`）の「困りごと見出しを常時展開」のうち、
    **カードの常時展開をやめる**。カテゴリ・困りごとの見出しを一覧で見渡せる構造と、ジャンプナビは維持する。
- 検索は入れない。

## 却下した選択肢（あれば）

- **検索**：40件程度なら見出しを見渡して開く方式で足りる。件数がさらに増えたら再検討。
- **カテゴリ単位の折りたたみ**：1つ開くと9〜17件が一度に出て、長さの問題が残る。
- **見出しだけを出す（制度名を出さない）**：何が入っているか開くまで分からず、2026-08-15にやめた「クリックしないと見えない」方式に近づく。

## 影響を受けるファイル

- `public/data/child_support_base.json`・`concern_mapping.json`（キャンバスの追加）
- `src/index.html`（実装時。Antigravity担当）
- `docs/agent-notes/design-specs/2026-10-07_concern-collapse.md`
- `docs/agent-notes/CURRENT_STATUS.md`
