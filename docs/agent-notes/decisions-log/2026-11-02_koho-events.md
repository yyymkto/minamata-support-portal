# 2026-11-02 広報みなまたからイベントを自動で取り込む

## 決めたこと

- 広報みなまたの新しい号を毎朝の処理で検知し、PDFからイベントを取り出して `events.json` に載せる。
- 掲載は自動で行う。公開前に11月号で全件を元のPDFと照合する。
- 水俣市外（芦北町・津奈木町など）のイベントは載せない（吉野さんの判断）。
- 制度情報の抽出は別の設計で扱い、人の確認を挟むIssue通知を想定する。

## 理由

- 11月号から選んだ11件は、お知らせにもイベント一覧にも載っていなかった。
- 10月号・11月号のPDFは文字を取り出せる。2026-09-16の議会だよりのようなスキャン画像ではない。
- 公開日が月によって変わるため（11月号は10/30）、決まった日ではなく毎日確認する。

## 残るリスク

- チラシが画像だけのページは読めない。確認した1ページの2件はどちらも市サイトから掲載済みだった。
- Geminiの抽出精度は未検証。設計書のタスク3で確認する。
