# [2026-11-18] 「ホーム画面に追加」を1行にする＋最小の文字を12pxにそろえる 設計書

**設計者**: Claude Code
**実装担当**: Antigravity
**状態**: 完了

## 概要

2026-11-18 のデザインレビューで、優先度が高いとした2点を直す。

1. **「ホーム画面に追加」の案内（`#add-to-home`）を1行のバーにする。**
   今は全タブでサイト名より上に約190pxの案内が出ていて、スマホの最初の画面の約3割を使っている。
   お知らせタブでは一行のお知らせ（`#a2hs-notice`）とあわせて、同じ案内が2回出る。
   **上に置くこと自体は運営者の判断（2026-10-21、コミット `9852db5`）なので変えない。** 縮めるだけ。
2. **11px・10px の文字を 12px（`text-xs`）にそろえる。** タグ・絞り込みの見出し・注意書きなどが小さく、
   高齢の方には読みにくい。

## データ構造

変更なし。ローカルストレージのキー `minamata_a2hs_dismissed`（既存）をそのまま使う。

## 画面・API仕様

### 1. 「ホーム画面に追加」バー（全タブ共通・タブの直下）

**見た目（スマホ幅 375px）**

```
┌───────────────────────────────────────┐
│ 📱 ホーム画面に追加できます  [追加する]  ✕ │  ← 高さ 56px 以下、1行
└───────────────────────────────────────┘
```

- 置き場所は今と同じ（グローバルタブ `nav` の直下、`#add-to-home`）。
- 中身は次の3つを横1行に並べる。375px で折り返さないこと。
  - 文言：「ホーム画面に追加できます」（`text-sm`、色 `text-ink`）
  - ボタン［追加する］：押すと既存の `handleA2HSAction()` を呼ぶ。見た目は今のボタンを小さくしたもの
    （枠線 `border-bay`、文字 `text-bay`、高さ `h-9`、左右余白 `px-3`）。
  - ✕ ボタン：`aria-label="閉じる"`、押せる範囲は縦横 36px 以上。
- 見出し（`<h2>ホーム画面に追加</h2>`）と説明文の段落は消す。
- 背景は `bg-baySoft`、下線 `border-b border-line`。左右余白は他の区画と同じ `px-4`、上下 `py-2`。
- イベントタブでカレンダー購読バーと続けて見せる処理（[index.html:543-546](../../../src/index.html) の
  `border-b` / `pb-1` の切り替え）は、新しいバーでも見た目が崩れないよう合わせて調整する。

**パソコン（`detectPlatform().os === 'desktop'`）の場合**

- 文言を「このサイトはブックマークできます（Ctrl＋D／Macは ⌘＋D）」に変え、［追加する］ボタンは出さない。✕ は出す。
- スマホでは Ctrl＋D の説明は出さない（今は全員に出ている）。

**バーを出さない条件**（どれか1つに当てはまれば `hidden`）

- ホーム画面から開いている（`isStandalone()` が true）
- 過去に ✕・［追加する］・一行のお知らせの ✕／［追加方法］のどれかを押した（`isA2HSDismissed()` が true）
- 追加が完了した（`appinstalled` を受け取った、または `userChoice.outcome === 'accepted'`）

**押したときの動き**

- ✕：`setA2HSDismissed()` を呼び、バーを隠す。
- ［追加する］：`setA2HSDismissed()` を呼び、`handleA2HSAction()` を呼ぶ（ブラウザの追加確認、なければ手順画面）。
  手順画面を閉じたあとにバーは出さない（一度見た人に繰り返し出さないため。今の一行のお知らせと同じ考え方）。

### 2. 一行のお知らせ（`#a2hs-notice`）を廃止する

- バーと役割が重なるので、`#a2hs-notice` の要素と `renderA2HSNotice()` を消す。
  ✕・［追加方法］の処理はバー側に移る（上の「押したときの動き」）。
- `hideA2HSUI()` から `#a2hs-notice` の処理を消す。

### 3. 「このサイトについて」に、いつでも使える入口を残す

バーを ✕ で消した人も、あとで追加できるようにする。

- `#about` の箇条書きの最後に1項目を足す：
  「スマホのホーム画面に追加すると、アプリのようにすぐ開けます。［追加方法を見る］」
- ［追加方法を見る］は `<button>`（見た目はリンク風：`text-bay underline`）。押すと `handleA2HSAction()` を呼ぶ。
- ホーム画面から開いているとき（`isStandalone()`）は、この1項目ごと出さない。

### 4. 最小の文字を 12px にそろえる

- `src/index.html` の `text-[11px]`（22か所）と `text-[10px]`（1か所、1703行目付近）を、すべて `text-xs` に置き換える。
  - 主な場所：絞り込みの見出し（177・181行目）、お知らせカードのタグ（671・672行目）、制度カードの補足・最終確認・共有ボタン、
    イベントカードのカテゴリ・申込バッジ・主催、各種注意書き。
- 置き換えで行の高さが増えて、はみ出し・折り返しの崩れが出ていないか、375px 幅で3タブとも確認する（タスク5）。
  崩れた場合は、文字を小さく戻さず、余白（`px-` / `py-`）を詰めて直す。どうしても収まらない場所は
  「実装時の疑問点」に書いて止める。

## 設計判断の理由（なぜこの設計にしたか）

- **上に置いたまま縮める（下に戻さない）**：上に置くのは運営者の判断。困っているのは「場所」ではなく「大きさ」と「2回出ること」なので、そこだけ直す。
- **✕ で消せるようにする**：毎回同じ案内が出ると、利用者は見なくなり、その分の画面が無駄になる。
  一度見た人には出さず、「このサイトについて」に入口を残せば、あとから追加したい人も困らない。
- **一行のお知らせを廃止する**：バーが1行になると、一行のお知らせと見た目も役割も同じになる。2つ残す理由がない。
- **既存のキー `minamata_a2hs_dismissed` を使う**：前に一行のお知らせを閉じた人には、新しいバーも出ない。
  その人はすでに案内を見ているので、それでよい。
- **12px を下限にする**：本文は 14px（`text-sm`）のまま。補足の文字だけを 12px にそろえる。
  13px 以上にするとタグの行や申込バッジが折り返しやすくなるため、まずは 12px にする。
