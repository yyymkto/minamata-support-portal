**実装担当**: Antigravity（UI）／ Claude Code（データ調査・JSON作成）

## 概要

「子育て支援制度」タブを、**「水俣市で受けられる子育て支援が一覧できる場所」**として
改装する。吉野さんの意図は「困っている人が探す場所」だけでなく、
**「水俣にはこういう支援がある」と示せる場所にしたい**というもの。

そのため次の3軸で進める。

1. **全体像を冒頭に示す**。タブの先頭に、水俣市の子育て支援を代表する事実を数件
   並べる（例：医療費は18歳まで自己負担なし）。個別の制度を探す前に、
   全体の手厚さが伝わる状態にする。
2. **説明文を事実寄りに書き直す**。現在の説明文は制度の仕組みを中立に述べるだけで、
   一番強い事実が埋もれている。後述の「アピールの方針」に沿って書き換える。
3. **掲載制度の件数を増やす**（現在27制度）。市サイトの子育て関連6カテゴリ＋学校教育・
   給食カテゴリを洗い出した結果、未掲載の有力候補が10件以上見つかった。特に
   **予防接種が1件も載っていない**、**奨学金が就学援助1件しかない**、
   **発達支援の窓口が無い**、**給食費支援が全く無い**という4つの穴が明確になった。

あわせて、現在のトーン（生成り色＋明朝見出し＋藍緑アクセント）は維持したまま
情報の階層を整理する。**折りたたみ・検索機能の追加は今回のスコープ外**とする
（「長すぎて辿り着けない」問題は別の設計書で扱う。下記「設計判断の理由」参照）。

## アピールの方針（この設計書の前提）

2026-08-26に「誘導的・勧誘的な言い回しは避けたい」と決め、タブ名を
「使える制度をさがす」から「子育て支援制度」に変えた経緯がある
（`decisions-log/`および`CURRENT_STATUS.md`参照）。今回の「アピールしたい」は
これと矛盾しない形で実現する。

**アピールは形容詞ではなく、事実の強さで行う。**

| 採用しない | 採用する |
|---|---|
| 「水俣は子育てしやすい街です」 | 「医療費は18歳まで自己負担なし」 |
| 「手厚い支援が受けられます」 | 「3〜5歳の保育料は無償」 |
| 「ぜひご活用ください」 | 「所得制限なし」 |

判断基準：**その文が公式ページに書かれた事実の言い換えで済むならOK。
書き手の評価や呼びかけが入るならNG。**

参考として、市自身の移住・定住促進サイトの子育て支援ページ
（`/ijyu/kiji0031921/`）は「18歳まで（18歳に達してから最初の3月31日まで）
医療費の自己負担がありません」を筆頭の売りにしている。市が何を強みと
考えているかの手がかりになる。

### 給食費支援（最優先・事実は確定済み／掲載方法は未決定）

**2026-09-16、吉野さん提供の一次資料により内容を確定した。**

出典：水俣市議会だより No.106（令和8年5月1日号）「令和8年度補正予算を可決」、
および令和8年度一般会計補正予算書（第1号）(款)9教育費 (項)5保健体育費

| | 小学校 | 中学校 |
|---|---|---|
| 事業名 | 学校給食費補助事業 | 水俣市学校給食費補助事業 |
| 予算額 | 6,304万円 | 3,088万円（予算書：30,885千円） |

予算書側の裏付け：節18「負担金、補助及び交付金」30,885千円、説明欄に

**確定した事実：小中学校とも給食費は実質無料。中学校分は国の制度の対象外であり、
水俣市独自の措置。** 対象の書き方は「市内小学校に在籍する児童について」
「市内中学校に在籍する生徒について」で、所得制限の記載はない。

**アピール材料としての価値が最も高い一件である。** 国の制度（2026年4月開始）は
公立小学校のみが対象のため、中学校まで全額補助している点は他自治体との差別化になる。
にもかかわらず、**市の公式サイトには給食費支援の制度ページが存在しない**
（「給食」カテゴリ（list00743）は給食だより・献立カレンダー・食育だよりの3件のみ）。
市民が公式サイトを探しても辿り着けない情報であり、このサイトが埋めるべき穴として
最も分かりやすい。

#### 決定1：`permanence` は `ongoing`、ただし年度を明記する（2026-09-16 吉野さん判断）

補正予算による事業のため単年度か恒久かは資料から読み取れないが、情報としての
価値を優先して掲載する。ただし**年度を明記して、いつ時点の話かが必ず分かる形に
する**（「給食費は無料です」ではなく「令和8年度は全額補助」と書く）。

- `description`・`conditions_note`に年度を必ず入れる。
- 年度が変わったら再確認が必要な項目として、`verification_status`にその旨を書く。
- `scripts/monitor_stock.py`は`official_url`のページ更新を監視する仕組みなので、
  リンクを持たないこの項目は監視対象外になる。**年度替わりの確認は人手で行う**
  必要がある（下記「運用上の注意」）。

#### 決定2：`official_url` を持たないカードを許容する（2026-09-16 吉野さん判断）

市の公式サイトに制度ページが無いため、リンクなしのカードを認める。
これは**スキーマとUIの両方の変更**を伴う。

### スキーマ変更：`official_url` の任意化と `source_note` の追加

現在、全27件が`official_url`必須を前提としている。給食費のように公式ページが
存在しない制度のために、次の2点を変更する。

```json
{
  "base_id": "school-lunch-subsidy",
  "title": "学校給食費の全額補助",
  "official_url": null,
  "source_note": "水俣市議会だより No.106（令和8年5月1日号）／令和8年度一般会計補正予算書（第1号）",
  ...

```

- `official_url`: **`null` を許容する**（既存27件は変更しない）。
- `source_note`: **新設。`official_url`が`null`のときのみ必須**。出典の名称を書く。
  URLではなく人が読む文字列。公式ページがある制度では書かない（または省略）。

**`official_url`が`null`の項目は、出典が公式サイト外であることを意味する。**
この状態を安易に増やさないため、次を原則とする。

> 公式サイトに制度ページが存在することを確認した上で、それでも無い場合にのみ
> `official_url: null` を使う。「探すのが面倒だから」は理由にならない。

## 画面仕様

このプロジェクトはAPIを持たないため画面仕様のみ。対象は `src/index.html` の
`#view-concern`（および共通関数 `renderConcernSet` / `concernSectionHTML` /
`serviceCardHTML`）。

**現在のトーン（`paper`/`ink`/`bay` の配色、明朝見出し、白カード）は変更しない。**
変えるのは階層の付け方だけ。

### 0. 冒頭に「全体像」セクションを追加（今回の主役）

`#view-concern` のヘッダー直下、カテゴリ一覧が始まる前に、水俣市の子育て支援を
代表する事実を数件並べる。**個別の制度を探す前に、全体の手厚さが伝わる状態を作る。**

```
　水俣市の子育て支援

　　医療費          18歳まで自己負担なし
　　保育料          3〜5歳は無償
　　給食費          （裏取り後に確定）
　　相談            妊娠期から切れ目なく対応（こども家庭センター）

　　※ 詳しい条件は下の各制度をご確認ください
```

- 掲載は**4〜5件まで**。増やすと「全体像」ではなく「もう一つの一覧」になる。
- 各行は「短い見出し語（医療費・保育料など）＋事実」の2列。**説明文は書かない。**
- 各行は該当する制度カードへのページ内リンクにする（クリックで下の該当箇所へ移動）。
- 色・書体は現在のトーンを踏襲する。**バナー的な装飾（グラデーション・大きな数字・
  アイコンの多用）はしない。** 落ち着いた事実の列として見せる。
- データは `child_support_base.json` に新設する `highlights` 配列から読む
  （下記データ構造参照）。HTMLに直書きしない。

#### `child_support_base.json` への追加（トップレベル）

```json
{
  "_schema_note": "...",
  "last_updated": "2026-09-16",
  "highlights": [
    {
      "label": "医療費",
      "fact": "18歳まで自己負担なし",
      "base_id": "child-medical-subsidy"
    },
    {
      "label": "保育料",
      "fact": "3〜5歳は無償",
      "base_id": "childcare-education-free"
    }
  ],
  "items": [ ... ]
}
```

- `label`: 短い見出し語（4文字程度まで）
- `fact`: 事実の言い切り。公式ページに書かれた内容の言い換えで済む範囲に限る
- `base_id`: リンク先の制度。`items`内に存在する`base_id`であること

`highlights` が存在しない・空配列の場合はセクションごと描画しない
（既存データとの後方互換のため）。

### 1. カテゴリ見出しに件数を添える

現在（[index.html:641](../../../src/index.html#L641)）はカテゴリ名のみ。
絞り込み後の実際の表示件数を右側に小さく添える。

```
妊娠・出産                                    6件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- 件数は `catSections` 計算時に確定する表示対象の制度数（重複を除いた実数）。
- 文字サイズは `text-xs`、色は `text-inkSoft`、`font-normal`（見出しと競合させない）。

### 2. 困りごと見出しの様式を変える（最重要）

現在、カテゴリ見出し（h2, `font-serif font-bold text-xl`）と困りごと見出し
（h3, `font-serif font-bold text-base`）がどちらも明朝の太字で、強弱が弱い。
困りごとは「〜について知りたい」という**問いかけ**なので、見出しというより
語りかけとして差別化する。

- h3を `font-serif font-bold text-base text-ink` から、**左に`bay`の縦罫線
  （`border-l-2 border-bay/40 pl-3`）＋ `text-[15px]` ＋ `font-medium`** に変更。
- 上の余白を広げる（`mt-6`）。カテゴリ内の区切りを視覚的に明確にする。
- 明朝体（`font-serif`）は維持する。

### 3. カード内の情報順を整理

現在（[index.html:526-545](../../../src/index.html#L526-L545)）の順序は
「種別バッジ＋最終確認バッジ → タイトル → 説明 → 警告 → 条件 → CTA」。
最終確認日がタイトルより上にあり、最初に目に入る情報としては優先度が低い。

変更後の順序：

```
[種別バッジ]                     ← 最終確認バッジはここから外す
制度名（明朝・太字）
説明文
（3年超の警告ボックスがあればここ）
（条件があればここ）
[ 申請する → ]
─────────────────
最終確認：2026-07-17            ← 下部へ移動、text-[11px] text-inkSoft
```

- 3年超の警告ボックス（`fresh.level === 'warn'`）は**現在の位置・見た目のまま維持**。
  これは目立つべき情報なので下げない。
- 下部の最終確認は区切り線（`border-t border-line`）の下に置く。

### 3b. リンクを持たないカードの表示（新規・給食費のために必要）

現在の `serviceCardHTML`（[index.html:537-541](../../../src/index.html#L537-L541)）は
必ずCTAボタン（「申請する」等）を描画する。`official_url`が`null`の場合、
`safeUrl()`は`'#'`を返すため、**そのままでは「申請する」を押しても何も起きない
壊れたボタンが出る。**

`official_url` が `null`（または未設定）の場合は次のようにする。

- **CTAボタンを描画しない。**
- 代わりに、カード下部に出典を明示する。

```
[費用の助成]
学校給食費の全額補助
市内の小学校・中学校に在籍する児童生徒の給食費を全額補助しています。
令和8年度は小学校分6,304万円、中学校分3,088万円を予算化。
中学校分は国の制度の対象外で、水俣市独自の措置です。

（条件の注記）令和8年度の補正予算に基づく事業です。年度ごとに
　　　　　　　予算が決まるため、最新の状況は市へご確認ください。
─────────────────
出典：水俣市議会だより No.106（令和8年5月1日号）
　　　※ この制度は市の公式サイトに専用ページがありません
最終確認：2026-09-16
```

- 出典行は `text-[11px] text-inkSoft`。CTAボタンと同じ視覚的重みにしない。
- 「※ この制度は市の公式サイトに専用ページがありません」は固定文言とする
  （`source_note`があるとき常に表示）。**利用者が「リンクが無いのは不具合ではない」
  と分かるようにするため。**
- `guideCardHTML`はカード全体が`<a>`なので、`official_url`が`null`の項目は
  `info_type: "guide"` にしない運用とする（給食費は`service`なので問題ない）。

### 4. 対象ステージの表示（任意・削ってよい）

`child_stage` / `household_type` は絞り込みにしか使われておらず、カード上では
見えない。種別バッジの隣に小さく並べると「自分の子に関係あるか」が一目で分かる。

```
[現金給付] 小学生・中学生
```

- 表示は `child_stage` が6ステージ全部を含む場合は「すべての年代」と省略する
  （27件中10件以上が全ステージ対象のため、そのまま並べると冗長）。
- `household_type` は空でない場合のみ「ひとり親」「障がい児」を表示。
- **この項目だけは吉野さんが選ばなかった方向（情報の追加）に踏み込むため、
  不要なら削ってよい。** 詳細は「設計判断の理由」参照。

### 5. ジャンプナビのスクロール位置の固定値を修正

現在 `scroll-mt-[180px]`（[index.html:640](../../../src/index.html#L640)）が
ハードコードされている。スマホ幅ではプロフィールチップ8個が2〜3行に折り返して
ヘッダーが高くなるため、ジャンプ時に見出しがヘッダーに隠れる。

- ヘッダー要素の実高さを取得してCSS変数（例 `--concern-header-h`）に設定し、
  `scroll-margin-top` をそこから算出する。
- 画面幅の変更時（`resize`）にも再計算する。

## 設計判断の理由

### 「アピールしたい」と「勧誘的な表現は避けたい」をどう両立させたか

2026-08-26に吉野さんは、誘導的なコピー案（タブ名「水俣で受けられる支援」等）を
見て「誘導するような文言は省きたい」と判断し、中立的な紹介表現に留めた経緯がある。
今回の「なんならアピールするところにしたい」はその決定の撤回ではなく、
**「事実が弱く書かれすぎていて、あるものが伝わっていない」という別の問題**への
指摘だと解釈した。

実際、`child-medical-subsidy`の説明文は「医療機関受診時の自己負担額の一部または
全部を助成する制度」となっており、市自身が移住サイトの筆頭で掲げている
「18歳まで自己負担なし」という事実が読み取れない。これは中立性の問題ではなく、
単に事実が正確に伝わっていない。

そこで「アピール＝事実の強さ」という基準を置き、形容詞・呼びかけは従来どおり
使わない方針とした。この基準なら2026-08-26の決定と衝突しない。

### 給食費が「一次情報主義」と衝突する点について

本プロジェクトは一次情報（公式ページ）で裏が取れるものだけを載せる方針で
運用してきた。しかし給食費支援は、**市の公式サイトに制度ページが無く、
議会だより（画像PDF）と予算資料にしか存在しない**。

「載せたい情報ほど公式サイトに無い」という状況は今後も起こりうるため、
今回は次の扱いとする。

- **推測では書かない。** 裏が取れなければ載せない（タスク0の完了条件）。
- 公式サイト以外を出典にする場合は、`verification_status`に**出典の種類
  （議会だより第◯号・予算資料等）と確認日を明記する**。通常の`official_url`とは
  性質が違うことが後から分かるようにする。
- `official_url`に適切なページが無い制度をどう扱うか（リンク先を持たないカードを
  許容するか）は、この設計書では決めない。タスク0で裏が取れた段階で改めて相談する。

### なぜ折りたたみ・検索を今回入れないか

吉野さんは改装の主題として「見た目・読みやすさの刷新」と「掲載制度の充実」を
選び、「長すぎて目的の制度に辿り着けない」は選ばなかった。そのため、構造そのものを
変える折りたたみ・検索は今回のスコープから外した。

ただし**制度を10件増やすと、現在の「16の困りごとを常時全展開」という構造では
ページはさらに1.4倍程度長くなる**。今回の階層整理（見出しの強弱・余白・件数表示）は
流し読みの手がかりを増やすので悪化を緩和できるが、根本解決ではない。
制度が40件を超えたあたりで折りたたみか検索が必要になる見込みで、そのときは
別の設計書を起こす。

### なぜ「対象ステージの表示」を任意として入れたか

これは吉野さんが選ばなかった方向（情報の追加）に属する。それでも仕様4として
書いたのは、階層整理の観点で「この制度は自分の子に関係あるか」が最上位の判断で
あり、それが今カード上で分からないため。ただし主題ではないので、判断は委ねる。

### なぜ予防接種を最優先の追加候補としたか

現在このサイトには予防接種の情報が1件も無い。乳幼児健診（`infant-checkup`）は
あるのに予防接種が無いのは、子育て世帯の実際の関心から見て穴が大きい。
また子宮頸がんワクチンは小6〜高1が対象で、現在手薄な「中学生・高校生の
子を持つ世帯」への数少ない接点でもある。

### 既存URLの差し替えを設計書に含めた理由

改装とは直接関係しないが、制度を追加する際に同じ失敗（年度限定の告知ページを
恒久制度として登録する）を繰り返さないため、先に基準を明確にしておく必要がある。
**新規追加時も「年度・改正年月がタイトルに入っているページは恒久ページを探す」を
原則とする。**

## 運用上の注意（この改装で新しく生じるもの）

### リンクを持たない項目は自動監視の対象外になる

`scripts/monitor_stock.py` は各制度の `official_url` にアクセスして、ページの
最終更新日の変化やリンク切れを検知し、週次でIssueを起票する仕組み。
**`official_url` が `null` の項目は、この監視から外れる。**

給食費補助は年度ごとの予算に基づく事業のため、本来もっとも変化を追う必要がある
にもかかわらず、自動監視が効かないという逆転が起きる。対応として次のいずれかが必要。

- **当面**：年度替わり（4〜5月）に人手で議会だより・予算資料を確認する。
  `verification_status` にその旨を明記しておく。
- **将来**：`monitor_stock.py` に「`official_url` が `null` の項目を、
  `last_verified` から一定期間経過したら通知する」仕組みを足す。
  今回のスコープ外だが、`official_url: null` の項目が増えるなら必要になる。

### 「全体像」の事実は古くなる

冒頭のハイライトは、年度や制度改正で変わりうる事実を短く言い切る形になる。
説明文より目立つ位置にあるため、**間違ったまま放置されたときの影響が大きい**。
`highlights` の各項目は、リンク先の制度の `last_verified` を実質的な鮮度の
根拠とみなし、元制度が古くなったらハイライトも見直す運用とする。
