# [2026-10-17] 子育て支援制度：固定部分を小さくする 設計書

**設計者**: Claude Code
**実装担当**: Antigravity
**状態**: 完了（2026-10-17 Antigravityによりタスク1〜3実装完了）

## 概要

「最新のお知らせ」タブの固定部分を小さくした変更（設計書 `2026-10-17_feed-header-compact.md`、本番反映済み）を、
「子育て支援制度」タブにも入れる（2026-10-17、吉野さんの依頼）。

手元で幅390px・高さ700pxに表示して測ったところ、固定部分はタブ48px＋ヘッダー約251px＝**約300px（画面の43%）**。
このうち、タイトル（h2）と説明文の固定をやめ、ページと一緒にスクロールさせる。
「あてはまるもの」の絞り込みボタンと、場面ごとのジャンプボタン（`#jump-nav`）は固定のまま残す（吉野さんの判断）。
固定部分は**約225px**になる見込み。

対象は「子育て支援制度」タブだけ。イベント・一人暮らし・若者支援タブは変えない。

<div id="view-concern">
  <div>                                      ← 固定しない（ページと一緒に流れる）

  </div>

  #concern-filter-notice / #concern-highlights / #concern-content（今のまま）

### 細かい決まり

1. **固定しない部分**（h2・説明文）
   - `<header>` の外に出し、`<div><div class="max-w-2xl mx-auto px-4 pt-4"> … </div></div>` で包む
     （お知らせタブと同じ形。外側の `<div>` にクラスは付けない）。
   - h2 のクラスは今のまま。説明文の `<p>` は `mb-3` を外す（間隔は次の固定部分の上余白で取る）。それ以外のクラスは今のまま。
2. **固定する部分**（`<header class="sticky top-12 z-30 bg-paper/95 backdrop-blur border-b border-line">`）
   - クラスは今のまま。内側の `<div>` は `max-w-2xl mx-auto px-4 pt-3 pb-3`（`pt-4` を `pt-3` に変える）。
   - 案内文・`#profile-tags`・`#jump-nav` の中身・クラスは今のまま。
3. **該当カードへ飛ぶ位置**：`updateHeaderOffsets()` は `#view-concern header` の高さを測って `--concern-header-h` を決めている。
   変更後は固定部分だけの高さが測られるので、**JavaScriptは変更しない**。ジャンプボタンやハイライトのリンクで飛んだとき、
   見出しやカードが固定部分の下に隠れず、すぐ下に来ることを確認する。
4. `id` は1つも変えない。
5. ページを開いた直後（スクロール前）の見た目は今とほぼ同じにする。

## 設計判断の理由（なぜこの設計にしたか）

- お知らせタブで入れた案A（タイトル・説明文を固定から外す）を、吉野さんがスマホで確認し「良い感じ」だったため、同じ形にそろえる。
- 「あてはまるもの」も流すと固定部分は約100pxまで減るが、吉野さんの判断で、お知らせタブの絞り込みと同じく固定のまま残す。
- お知らせタブの設計書では「該当カードへ飛ぶ」機能があるため子育てタブは見送っていたが、確認したところ、
  飛び先の位置は固定部分（`<header>`）の高さを毎回測って決めているため、HTMLの並び替えだけで正しく追従する。
