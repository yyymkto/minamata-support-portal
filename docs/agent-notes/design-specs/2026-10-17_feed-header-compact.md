# [2026-10-17] 最新のお知らせ：固定部分を小さくする 設計書

**設計者**: Claude Code
**実装担当**: Antigravity
**状態**: 完了（2026-10-17 Antigravityによりタスク1〜3実装完了）

## 概要

スマホで「最新のお知らせ」タブを開くと、画面上部に固定される部分（タブ＋ヘッダー）が大きすぎる。
本番サイトを幅390px・高さ700pxで表示して測ったところ、固定部分は約380px（画面の54%）あり、
記事が読める部分は約320px（カード1枚半くらい）しかなかった（2026-10-17、吉野さんの指摘）。

ヘッダーのうち「最終更新・サイト名・説明文」は一度読めば十分な情報なので、固定をやめてページと一緒にスクロールさせる。
固定するのは、グローバルタブ・検索欄・絞り込みのボタン（2段）だけにする。
固定部分は約240px（画面の35%くらい）になる見込み。

対象は「最新のお知らせ」タブだけ。他のタブは変えない（下の「設計判断の理由」参照）。

### 細かい決まり

1. **固定しない部分**（最終更新の行・h1・説明文）
   - `<header>` の外に出し、ふつうの `<div>` で包む。中身・クラス・`id`（`updated-at` など）は今のまま。
   - 背景は `bg-paper`（ページの地の色）。区切り線は付けない。
   - 余白：上 `pt-4`（今と同じ）、下はなし（説明文の下の間隔は、次の固定部分の上余白で取る）。
2. **固定する部分**（`<header class="sticky top-12 z-30 bg-paper/95 backdrop-blur border-b border-line">`）
   - クラスは今のまま。
   - 中身は検索欄と絞り込み2段。検索欄の外側の余白は `pt-3`（今の `mt-4` の代わり）。それ以外の余白は今のまま。
   - 検索欄・絞り込みボタンの見た目・動きは変えない。
3. **ページを開いた直後（スクロール前）の見た目は、今とほぼ同じ**にする。違いは検索欄の上の間隔が少し変わる程度。
4. **スクロールしたとき**：最終更新・サイト名・説明文は上に流れて見えなくなり、検索欄と絞り込みがタブのすぐ下に貼りつく。
5. 「このサイトについて」のリンク（`#about`）はそのまま動くこと。
6. `id` は1つも変えない（JavaScriptから参照しているため）。JavaScriptは変更しない想定。
7. 絞り込みや検索を変えたときのスクロール位置の動きは、今と同じでよい（今回は変えない）。

## 設計判断の理由（なぜこの設計にしたか）

- 吉野さんと3案を比べた（2026-10-17）。
  A：サイト名・説明文を固定しない（今回）／B：Aに加えて絞り込みを「絞り込み」ボタン1つにまとめる／
  C：下にスクロールすると固定部分を隠し、上に戻すと出す。
- Aは HTMLの並び替えだけで済み、JavaScriptを触らないので壊れにくい（作業1時間程度）。
  Cは検索中にキーボードが出たときの動き、iPhoneの跳ね返りでのチラつき、他タブの「該当カードへ飛ぶ」の位置計算の
  手直しが要り、半日〜1日かかる。
- Cだけを入れても、上に戻したときに今の大きな固定部分（約380px）が出てくる。先にAで固定部分を小さくしておけば、
  あとでCを足すときも無駄にならない。吉野さんの判断で「Aから」。使ってみてまだ狭ければ、お知らせタブにCを足す。
- 子育て支援制度・イベントタブも固定部分が大きいが、「該当カードへ飛ぶ」機能が固定部分の高さ
  （`updateHeaderOffsets()`）に依存しているため、今回は触らない。お知らせタブにはこの機能が無い。
